# Mosaic data sources and current coverage

**Product geography:** Maharashtra, India.
**Data snapshot:** 1 Nov 2026.

## Data layers

| Layer | Source and licence | Current coverage and method |
|---|---|---|
| Streets, cities, and localities | [OpenFreeMap Liberty](https://openfreemap.org/quick_start/), vector tiles derived from OpenStreetMap; OSM data ODbL 1.0 | Live basemap centered on Maharashtra. Labels prefer `name:en`, then a Latin-script name, then the source name. Detail depends on OSM completeness, zoom, and internet access. |
| Place-name search | [Photon](https://github.com/komoot/photon), an OpenStreetMap-based geocoder | Search uses India country code, Maharashtra bounds, and filters results to Maharashtra. It needs no API key; the public service has no availability guarantee. OSM attribution is displayed with suggestions. |
| Population | [WorldPop Global 2](https://hub.worldpop.org/project/categories?id=3), modeled 2025 population, 1 km raster, CC BY 4.0 | The India raster is clipped and aggregated to Maharashtra H3 resolution 4 cells. The current browser grid contains 213 cells. Finer cells split source population in proportion to area, so those are estimates. |
| Business and service places | [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), ODbL 1.0, retrieved through Overpass | 37,592 mapped features are aggregated to H3 resolution 4 across Maharashtra. The snapshot includes `shop`, `office`, `craft`, and selected amenity, healthcare, leisure, and tourism tags. OSM coverage varies and is not an official business registry. |
| Administrative boundary | [geoBoundaries](https://www.geoboundaries.org/api.html), CC BY 4.0 | Only the Maharashtra ADM1 outline is loaded by the browser. |
| Hexagons | H3 generated by Mosaic | The source grid is resolution 4. The radius control displays resolutions 2–6. Coarser cells aggregate source cells; finer cells proportionally allocate population and business totals from parent cells. |

## Score and limitations

The relative comparison index ranks Maharashtra cells using population density (60%) and inverse category density (40%). Scores are shown where the selected category is present in the source snapshot and business coverage is complete. Scores indicate relative differences in mapped data; they do not predict sales or guarantee that every business is mapped.

## Refresh

- `npm run data:maharashtra-population` retrieves the state boundaries, WorldPop raster, and business snapshot, then rebuilds browser assets.
- `npm run data:maharashtra-businesses` refreshes OSM business counts for Maharashtra only.
- `npm run data:maharashtra-boundaries` refreshes state boundaries and rebuilds the browser assets from local base data.
- `npm run data:maharashtra` regenerates the public grid and state boundary from local source files.

Large source downloads and intermediate files live under ignored `data/raw/`. Do not treat failed or unqueried OSM data as a zero business count.
